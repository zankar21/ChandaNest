# Slide Text

1. Title
- ChandaNest
- Enterprise real estate platform for tier-2 India

2. Problem / Market Context
- Discovery is fragmented across brokers, portals, and local WhatsApp groups
- Buyers lack verified data and consistent media
- Owners struggle to list and manage enquiries

3. Solution Overview
- Single platform for owners, agents, and admins
- Verified listings, signed media, and structured workflows
- Designed for Chandrapur-first scale

4. Home Experience
- Search-first landing with featured listings
- Clean filters and quick access to key categories

5. Property Cards
- At-a-glance price, area, and type
- Consistent badges for status and intent

6. Map Discovery
- Pin-based exploration by locality
- Quick previews without leaving the map

7. Property Details
- Premium gallery, price clarity, and map context
- Highlights and specs grouped for scan speed

8. Owner Add Listing
- Guided form with clear steps
- Media upload built in

9. Owner Dashboard
- Track listing status and visibility
- View enquiry counts and response prompts

10. Agent Dashboard
- Portfolio overview and lead pipeline
- KPI cards for conversions and activity

11. Admin Panel
- Moderation queue with approve/reject controls
- Status filters for fast triage

12. Workflow: Submit to Publish
- Draft to submit to admin review
- Publish only after required fields and media

13. Trust, Compliance, and Media
- Owner KYC and signed media URLs
- Audit-ready listing changes

14. Metrics and Growth Targets
- Focus on verified inventory in Chandrapur
- Target conversion and enquiry response KPIs

15. Roadmap and Next Steps
- Expand to more cities
- Deeper analytics and automation
- Enterprise onboarding at scale
